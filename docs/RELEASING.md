# Public release procedure

The public repository is a reviewed export, not a mirror of private Git history. Maintain a clean separation of deployment configuration and source. Review each export for secrets, lint PHP, run the protocol, configuration and storage suites, and record production preflight and live acceptance evidence independently. Never push private refs or include private configuration, signed tickets, or correspondence contents. Tag the reviewed source commit. The GPL-2.0-or-later license applies to this reference implementation. Publication is not itself a deployment.

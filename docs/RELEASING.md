# Public release procedure

Publish reviewed allowlisted snapshots only. Never merge or mirror private history. Before every public change, review all source, configuration, archives and Git history for confidential information, including commit/tag identities; rerun syntax, protocol, configuration and applicable integration tests. Use an approved public commit identity, update VERSION and CHANGELOG.md, and tag the exact verified tree. Record limitations and deployment status separately. Do not publish private routing, credentials, signing material, logs or messages. The license for the reviewed distribution is GPL-2.0-or-later.
